# What this build contains, and under which licence

**Rhapsode's own source code is MIT licensed.** See `LICENSE`. That is the licence of
the source: a *built* Rhapsode is distributed as GPL-3.0 as a whole, because the
narration engine phonemises text through eSpeak NG, which is GPL-3.0. Rhapsode's own
code stays MIT, and every component keeps its own licence:

| Component | Version | Licence |
| --- | --- | --- |
| `phonemizer` (Python bindings to eSpeak NG) | 3.6.0 | GPL-3.0-or-later |
| eSpeak NG (library and its data files) | 1.52.0 | GPL-3.0 |
| `libsndfile` (via `soundfile`) | 1.2.2 | LGPL-2.1 |
| `libheif` (via `pillow-heif`) | 1.23.6 | LGPL-3.0 |
| FFmpeg inside the OpenCV wheel (unused, and stripped from built distributions) | 5.1 | LGPL-2.1-or-later |
| FFmpeg for MP3 export and chapter films (gyan.dev release essentials, downloaded by the app on request, not bundled in the installer) | 9.1 | GPL-3.0 |

The licence texts are in this folder, beside this notice. The source for the GPL
and LGPL components — and for everything else in this build — is listed in
`SOURCES.md`, with a written offer to provide it.

Recipients of this build may study, modify and redistribute those components under
their own terms. Nothing here restricts your use of Rhapsode itself.

Full inventory, including the MIT and Apache-2.0 dependencies and the model
weights: `THIRD_PARTY.md`.
